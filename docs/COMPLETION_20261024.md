# ttp_asf 后续补全与验收

日期：2026-10-24。发行版本：`2026.10.24`。

## 修改

属性与封面保留语言索引。非默认语言枚举为 Name[lang=N]；无后缀键优先默认语言，明确后缀只更新所选语言；空属性名被拒绝。

## 验证

用系统 WM 元数据编辑器建立日语 Title，分别修改默认／日语值并重开，三系统均保持另一语言不变。实际 WMA 播放通过。

Windows 11、XP SP3 x86、Win7 SP1 的组合回归各 33 项通过，其中 19 组 PCM 样本数及校验相同。这是组合测试数量，不代表本插件单独具有 33 个独立用例。Win11 按用户要求代为现代 Windows 验证，无独立 Win10 实测。

## 保留边界

系统 WM／DMO 解码依赖保留。[后续 DMO／重复属性复核](DMO_MULTIVALUE_FOLLOWUP_20261024.md)补充四类本机解码、输出容量和 Reset 检查；同名重复值能够完整枚举，修改其他字段保持不变，Set 仍替换所选语言的同名组。DRM、第三方 DMO、逐项多值编辑和所有封面布局仍非全覆盖。

测试代码和样本只保存在工作区 `rebuild/tests/plugins_complete_20261024`，不进入 Action 或发行 ZIP。运行 ZIP 仅含 DLL 与 SHA256SUMS；许可证留在仓库及既有对应源码包。本轮没有升级上游依赖版本或增加外部解码 DLL。
